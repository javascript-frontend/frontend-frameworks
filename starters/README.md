# Free Frontend Starter Templates (2026)

Every starter below is MIT-licensed, TypeScript-ready, and kept intentionally minimal so you can ship without stripping out bloated demo code.

## Included Starters

| Starter | Stack | Best For | Copy Command |
| :--- | :--- | :--- | :--- |
| [`react-vite-ts-saas`](react-vite-ts-saas/) | React 19.3 + Vite + TypeScript | SaaS dashboards, AI workspaces, SPAs | `npx degit javascript-frontend/frontend-frameworks/starters/react-vite-ts-saas my-app` |
| [`vue3-vite-ts-app`](vue3-vite-ts-app/) | Vue 3.5 + Vite + TypeScript | Balanced web apps, internal portals | `npx degit javascript-frontend/frontend-frameworks/starters/vue3-vite-ts-app my-app` |
| [`svelte5-vite-ts-app`](svelte5-vite-ts-app/) | Svelte 5.57 + Vite + TypeScript | Fast, small-bundle interactive apps | `npx degit javascript-frontend/frontend-frameworks/starters/svelte5-vite-ts-app my-app` |
| [`astro-seo-landing`](astro-seo-landing/) | Astro 7.4 + Zero-JS HTML | SEO content sites, docs, product landings | `npx degit javascript-frontend/frontend-frameworks/starters/astro-seo-landing my-site` |

## Quick Start

```bash
npx degit javascript-frontend/frontend-frameworks/starters/react-vite-ts-saas my-app
cd my-app
npm install
npm run dev
```
